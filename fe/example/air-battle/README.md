# 星河空战

一个不依赖图片或音频资源的 Canvas 2D 微信小游戏示例。工程入口和生命周期组织参考微信开发者工具 QuickStart，飞机、敌机、粒子和界面均由本项目原创绘制。

## 操作

- 点击屏幕开始游戏。
- 移动端按住并拖动战机；PC 端开始后只需移动鼠标，战机会自动跟随并射击。
- 红色道具恢复一点生命，蓝色道具提供 6 秒双发快速射击。
- 最高分通过 `wx.getStorage` / `wx.setStorage` 保存在当前小程序空间。

## 编译

在 `fe` 目录执行：

```sh
pnpm compile
```

Web 容器会在应用列表中显示 `Dimina 空战`，其 appId 为 `wx9f8c2d7e6a5b4c3d`。原生三端使用仓库 `shared/jsapp/wx9f8c2d7e6a5b4c3d` 中的同一份编译包。
